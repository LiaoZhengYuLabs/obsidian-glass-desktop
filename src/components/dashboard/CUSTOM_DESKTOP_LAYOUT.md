# 自定义桌面布局

## 调整依据

- 当前主屏幕为 3200x2000，系统缩放后工作区约为 1600x1000 逻辑像素。
- 顶部 Seelen 状态栏占用约 50 逻辑像素，底部 MyDockFinder Dock 占用桌面底部安全区。
- 原 Dashboard 位于左侧并纵向展示六张卡片，与自动隐藏应用栏形成双重左侧视觉重量。

## 新布局

- 左侧：保留应用栏，宽度从 90 缩至 78，高度从 590 缩至 540；继续自动隐藏，并在全屏窗口出现时进入游戏/电影安全模式。
- 中央：不放任何常驻组件，留给浏览器、Codex、VS Code 和视频内容。
- 右上：Dashboard 改为 392x500 的轻量控制台，默认不置顶。
- 日常板块：时间天气、正在播放、系统监控、今日待办。
- 开发板块：工作区状态、AI CORE、GitHub、快捷工具。

## 性能

- 前台上下文每 2 秒读取一次，只调用 Win32 窗口信息，不截屏、不录制、不保存窗口内容。
- 媒体按钮只发送 Windows 标准播放/暂停媒体键。
- 原系统监控、GitHub 和本地 JSON 的刷新频率保持不变。
- Dashboard 不运行时没有新增后台负载。
