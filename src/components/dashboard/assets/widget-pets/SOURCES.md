# Widget Pet Sources

The desktop widgets use Petdex sprite packs converted losslessly from WebP to PNG for WPF compatibility. The original 8 x 9 animation grid is preserved.

| Widget | Theme | Petdex pet | Source |
| --- | --- | --- | --- |
| WeatherCard | Glacier blue | Prompt Penguin | https://petdex.dev/pets/prompt-penguin |
| FeatureCard | Lavender floral | Fine Pup | https://petdex.dev/pets/fine-pup |
| ClockCard | Midnight moonlight | Peri the Owl | https://petdex.dev/pets/peri-the-owl |
| CalendarCard | Arctic aurora | Nightly Fox | https://petdex.dev/pets/nightly-fox |
| BatteryCard | Bamboo green | Cloudy | https://petdex.dev/pets/cloudy |
| MediaCard | Mint botanical | Silver Shorthair | https://petdex.dev/pets/silver-shorthair |
| AppUsageCard | Amber autumn | Little Deer | https://petdex.dev/pets/little-deer |
| PhotoCard | Cream floral | Byte Bunny | https://petdex.dev/pets/byte-bunny |

Animation rows follow the Petdex standard layout: Idle, Run Right, Run Left, Waving, Jumping, Failed, Waiting, Running, and Review. Pet packs are user-submitted fan art; ownership and takedown information remain on each Petdex source page.
