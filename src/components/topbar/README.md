# 桌面媒体中心

这套增量升级保留现有 Seelen UI 顶部栏的全部项目、顺序和点击功能，只追加“截图库”“录像”“摄像头”“中/EN”，不重建桌面，也不修改 Windows 核心文件。配置已适配 Seelen UI 2.7 的新版工具栏格式。

## 顶部入口

- **截图**：保留原有 Windows 截图工具入口。
- **截图库**：打开媒体面板，可直接截取整个桌面、调用 Windows 区域截图、浏览历史图片。
- **录像**：开始或停止屏幕录像，历史 MP4 会显示缩略图。
- **摄像头**：生成可移动的实时摄像头窗口，或开始/停止摄像并浏览历史录像。
- **中/EN**：在简体中文输入与 English (US) 之间切换，不添加繁体输入法。

三个分类分别保存在“图片/桌面媒体中心/截图”“屏幕录像”“摄像头录像”。在任何分类或子目录中都可以点击“新建文件夹”，不会删除已有媒体。

屏幕录像使用本机已有 FFmpeg，24fps、H.264 ultrafast，优先保证桌面流畅度；摄像头预览使用 FFplay。录像页现在提供独立的录像开关、红色运行状态灯和 `HH:MM:SS` 实时录制时长。录像期间再次点击顶部“录像”即可返回面板查看时长或停止录制。

## Dock 倒影

MyDockFinder 原配置中倒影开关已开启，但透明度为 0。本安装将透明度设为 34，并补齐模糊、偏移和停止点参数，使所有 Dock 应用统一显示柔和倒影。

底部媒体进度由同级目录 `DockMediaProgress` 提供。它读取 Windows 原生媒体会话，把电影、视频或音乐的当前进度显示在对应 Dock 应用下方；只在鼠标靠近 Dock 时出现，不遮挡全屏画面。

安装和配置过程不会主动打开媒体面板。面板只在用户点击顶部“截图”“录像”或“摄像头”后出现。

## 恢复

运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\restore.ps1
```

恢复只还原 Seelen 顶栏和 MyDockFinder 配置，已经录制的媒体与自定义文件夹会保留。
