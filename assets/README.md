# Assets

This directory stores the catalog and sanitized public screenshots. Add binary assets locally after checking ownership and redistribution rights.

- `manifest.json` records the current application/icon roles, deep-space source, and Animal Trail catalogue boundary.
- `icons\` is ignored by default because icons may be user-supplied or third-party.
- `wallpapers\` and media folders are ignored by default. Sanitized PNGs under `screenshots\` may be committed.
